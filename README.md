# Elara AI & OS

**Elara AI & OS** is an AI-powered desktop assistant and software project developed by **Sparsh Saxena**.

## About

Elara AI & OS is a software project developed and maintained by **Sparsh Saxena**.

It combines AI, voice interaction, computer vision, automation, GUI components, maps, skills, and modular software components.

## Features

- AI-powered desktop assistant
- Voice interaction and speech features
- AI question answering and conversations
- Computer vision and image understanding
- OCR and screen analysis
- Desktop GUI
- Automation and commands
- Maps and location features
- Skills and plugins
- Phone and device-related components
- Website generation
- ChatGPT-style conversations

## Experimental Features

### Gesture-Controlled Floating Desktop Interface

Elara also has an experimental camera-based interaction system developed and tested privately by the developer.

The system uses live camera input and hand gestures to interact with floating desktop interface elements.

Current experimental capabilities include:

- Camera-based interaction
- Hand gesture interaction
- Floating desktop interface elements
- Gesture-controlled movement
- Gesture-controlled resizing
- Repositioning floating elements
- Touch-free desktop interaction

**Status: Experimental / Private Development**

This feature is currently being tested privately and may be expanded in a future version of Elara AI & OS.
